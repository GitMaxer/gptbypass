# GABA с reversal-потенциалом: математика защиты V_rest

**Вопрос (Этап 6):** как математически реализовать
`I_GABA = g_GABA·(V − E_Cl)`, чтобы мембрана не уходила ниже `V_rest`
при глубоком торможении? — критично для протокола сна.

**Краткий ответ:** `E_Cl = V_rest` + точный экспоненциальный интегратор +
KCC2-гомеостат. Тогда `V ≥ V_rest` — **инвариант по построению**, при
любой глубине торможения и любом шаге интегрирования. Полный вывод ниже.

---

## 1. Постановка

Мембрана (conductance-based LIF, проводимости нормированы на утечку g_L = 1):

```
tau_m dV/dt = (V_rest − V) + G_e·(E_exc − V) − g_GABA·(V − E_Cl) + sigma·xi(t)
```

где `G_e = g_AMPA + g_NMDA·B_Mg(V) ≥ 0` — суммарная возбуждающая проводимость
(`B_Mg` — блок Mg²⁺ по Jahr–Stevens), `g_GABA ≥ 0`, `xi` — 5-HT-модулированный
шум. Все потенциалы в мВ: `V_rest = −70`, `E_exc = 0`, `E_Cl ≈ −70`.

Ключ — знак GABA-тока: при `V > E_Cl` ток тормозит, при `V < E_Cl` —
**деполяризует**. GABA — «тормоз с обратной связью», а не «толкатель вниз».

## 2. Неподвижная точка: выпуклая комбинация

Сгруппируем линейную часть (B_Mg замораживаем по текущему V — монотонный
мягкий множитель, не меняющий структуру):

```
dV/dt = −lam·(V − V_inf),     lam = (1 + G_e + g_GABA)/tau_m > 0

            V_rest + G_e·E_exc + g_GABA·E_Cl
V_inf = ────────────────────────────────────────────          (*)
                 1 + G_e + g_GABA
```

Знаменатель равен сумме числителейых весов, поэтому **V_inf — выпуклая
комбинация трёх потенциалов** `V_rest`, `E_exc`, `E_Cl` с неотрицательными
весами `1/(1+G_e+g)`, `G_e/(…)`, `g_GABA/(…)`.

**Следствие (ядро ответа).** Если `E_Cl ≥ V_rest` и `G_e ≥ 0`, то

```
V_inf ≥ V_rest    при ЛЮБОМ g_GABA ∈ [0, ∞)
```

— глубокое торможение не может увести равновесие мембраны ниже покоя.

## 3. Специальный случай: чистый шунт

При `E_Cl = V_rest` и `G_e = 0` (глубокий сон: NMDA закрыт Mg²⁺, входа нет —
биология сама зануляет возбуждение, т.к. `B_Mg(−70 мВ) ≈ 0.04`):

```
V_inf = V_rest·(1 + g_GABA)/(1 + g_GABA) = V_rest   — ТОЧНО, для любого g_GABA
```

То есть сколь угодно сильная GABA-проводимость **не гиперполяризует**:
`I_GABA → 0` по мере приближения `V → E_Cl = V_rest`. Эффект глубокого
торможения — не смещение потенциала, а **ускорение релаксации**:

```
tau_eff = tau_m/(1 + g_GABA) → 0    (шунт: мембрана «прилипает» к покою)
```

Это в точности желаемая картина N3: тишина + стабильность, без провала.

## 4. Инвариант траектории

Решение линейного ОДУ: `V(t) = V_inf + (V(0) − V_inf)·e^(−lam·t)` —
монотонная экспоненциальная релаксация без пересечения `V_inf`. Отсюда

```
V(0) ≥ V_rest,  E_Cl ≥ V_rest,  G_e ≥ 0   ⟹   V(t) ≥ V_rest   ∀t ≥ 0    ∎
```

(если `V(0) ≥ V_inf`, траектория монотонно убывает к `V_inf ≥ V_rest`;
иначе монотонно растёт — в обоих случаях ниже `min(V(0), V_inf) ≥ V_rest`
не опускается).

## 5. Численная гарантия: точный интегратор (анти-Эйлер)

Явный Эйлер при глубоком торможении обязан условия `dt < 2·tau_eff`,
где `tau_eff = tau_m/(1+g_GABA)`. Уже при `g_GABA = 50`, `tau_m = 20 мс`:
`tau_eff ≈ 0.39 мс << dt = 1 мс` — множитель `1 − dt/tau_eff = −1.55`,
|множитель| > 1: **численная расходимость** (демо T2 в верификации: V
падает до −3.4·10¹² мВ). Эйлер «проваливает» мембрану ниже V_rest чисто
численно — безо всякой биологии.

Решение — интегрировать линейную часть **точно**:

```
V(t+dt) = V_inf + (V − V_inf)·exp(−lam·dt)                     (**)
```

— безусловно устойчиво при **любом** dt, сохраняет инвариант раздела 4
(выпуклая комбинация `V(t+dt) ∈ [min(V, V_inf), max(V, V_inf)]`), стоит
один `exp` на вектор нейронов. Шум — точным членом Орнштейна–Уленбека:

```
V += sigma·sqrt((1 − exp(−2·lam·dt))/(2·lam))·randn
```

## 6. KCC2-гомеостат: защита от коллапса Cl⁻

В биологии при интенсивной активности Cl⁻ накапливается и `E_Cl` может
упасть ниже `V_rest` (отказ хлорного насоса KCC2) — тогда GABA становится
гиперполяризующей ниже покоя. В протоколе сна это главный риск.

Модель насоса — одна строка:

```
E_cl_eff = max(E_cl_raw, V_rest)                                (***)
```

Контрастный опыт (верификация, тест T3 / стадия SLEEP):
- `E_Cl = −85 мВ`, гомеостат выключен: `V_min → −84.3 мВ` — **провал**;
- то же + гомеостат: `V_min = −70.000000 мВ` — инвариант восстановлен.

## 7. Стохастика (5-HT) и жёсткий предохранитель

Строгая нижняя граница с аддитивным шумом невозможна в принципе — но:
1. в N3 тонус 5-HT → минимум (расписание сна зануляет `sigma`), мембрана
   не «дёргается»;
2. финальный `clamp(V, min=v_floor)` — предохранитель по построению
   (в протоколе сна `v_floor = V_rest`; в остальных режимах −90 мВ).

Дрейф V_min от шума — порядка `±3·sigma/√(2·lam) ≈ 2–3 мВ` — это не
тормозный провал (см. подпись метрики `v_min` в «Экзамене»).

## 8. Итоговая тройная защита (реализация `neurons.py`)

```python
# 1) шунтирующий режим: E_cl >= V_rest (KCC2, e_cl_effective)
E_cl_eff = torch.clamp(E_cl_raw, min=V_rest)
# 2) ТОЧНЫЙ шаг мембраны — безусловно устойчив, V_inf из (*)
lam   = (1 + G_e + g_GABA) / tau_m
V_inf = (V_rest + G_e*E_exc + g_GABA*E_cl_eff) / (1 + G_e + g_GABA)
V     = V_inf + (V - V_inf) * torch.exp(-lam * dt)     # (**)
# 3) предохранитель протокола сна
V     = torch.clamp(V, min=v_floor)
```

Свойства (все проверены верификацией автоматически):

| Свойство | Статус |
|---|---|
| `V_inf = V_rest` при `E_Cl = V_rest`, любом `g_GABA` | T1, T1b: V_min = −70.000000 при g=50 и g=500 |
| Инвариант `V ≥ V_rest` траектории | T1/T1b (1000–2000 шагов, точность 1e-6) |
| Эйлер проваливается/расходится | T2: V_min ~ −3.4e12 мВ |
| KCC2 спасает от коллапса Cl⁻ | T3: −84.3 → −70.0000 |
| Выпуклость V_inf (1000 случ. конфигураций) | T4: min V_inf = −69.90 ≥ V_rest |
| N3 протокола сна: `g_GABA ≈ 3.5`, 300 шагов | SLEEP: V_min(N3) = −70.0000, тишина, быстрый возврат в W |

## 9. Бонус: S7 получает безопасное аварийное торможение

Гомеостатический стабилизатор S7 при всплеске активности добавляет
`surge → g_GABA` (до 1.5). Раньше (до Этапа 6) аварийный GABA-всплеск сам
мог «провалить» мембрану; теперь шунтирующий GABA с `E_Cl = V_rest`
физически неспособен это сделать — S7 может тормозить сколь угодно сильно
без риска для сомы. Это системное следствие новой арифметики торможения.
