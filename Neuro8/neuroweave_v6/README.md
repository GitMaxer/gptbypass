# NEUROWEAVE v6.0 — «Spiker»

Живая самоулучшающаяся пульс-сеть (SNN). Консолидированная сборка Этапов 1–6
на основе единого концепта v4.0.

> Статус Этапа 6 (**Масштабирование**): GABA с reversal-потенциалом +
> математика защиты V_rest; быстрый контур в `torch.cuda.CUDAGraph` (>2x);
> гибридный режим «Экзамен»; масштабирование при постоянном fan-in.

## Архитектура

```
                    ┌────────────────────────────────────────────────┐
 токены ──cur──►  ЗОНА A «сенсорная»          (изоляция зон — по      │
                    │   │  построению: рекуррентные связи только      │
              gate_B│   │gate_C               ВНУТРИ зоны; мосты —    │
                    ▼   ▼                     только явные проекции)  │
              ЗОНА B «синтаксис»   ЗОНА C «логика»                    │
                    │   │                                                    │
                    └───┬────►  ЗОНА D «ассоциативная/контекст»          │
                        │                                                    │
   WTA (soft, по зонам)◄─┘   ◄── NE-пульс (детектор |ctx − ctx_ema|)      │
   быстрый контекст ctx[2] ──► стробы маршрутизации gate_B / gate_C      │
                    │                                                     │
   I-интернейроны каждой зоны ──g_GABA──► E-клетки (reversal!)           │
   сон: гуморальный g_sleep + S7 surge (шунтирующие — безопасные)        │
                    │                                                     │
   нейрохимия: ACh (сома: v_th), 5-HT (шум), DA (пластичность),       │
              NE (заострение WTA) — тензорные расписания [T, Z]          │
                    │                                                     │
   ВСЁ это = один шаг FastLoop.step() → захватывается CUDA Graph целиком │
                    └────────────────────────────────────────────────┘
```

- **Мембрана**: conductance-based LIF, точный экспоненциальный интегратор,
  AMPA/NMDA (Mg²⁺-блок Jahr–Stevens), **GABA с reversal** `I = g·(V − E_Cl)`.
- **Зоны**: A (сенсорная), B (синтаксис), C (логика), D (ассоциативная);
  физическая изоляция — связность с фиксированным fan-in, межзонные
  мосты только через стробируемые проекции.
- **S7** — гомеостатический стабилизатор (Этап 5, «спасла проект»):
  GABA-всплеск при перегреве, ACh-подкачка при молчании, NaN-скраб.
- **w_slow** — медленные веса связей + readout; формируются претрейном
  (дельта-правило readout + трёхфакторный Хебб под DA), на «Экзамене»
  замораживаются (дрейф строго 0, `torch.equal`).

## Быстрый старт

```bash
pip install -r requirements.txt          # torch >= 2.0
python verify_cuda_graphs.py             # полная верификация (CPU/GPU)
```

Отдельные прогоны:

```bash
python scripts/run_sleep.py              # протокол сна + патология Cl-

python scripts/run_exam.py --graph       # «Экзамен» целиком в CUDA Graph
python scripts/run_scaling.py --factors 1,2,4,8 --steps 500
```

## История этапов

- **Этапы 1–3**: синтез концепта v4.0, стрес-тест, многоконтурная архитектура
  (ACh-сома, 5-HT-шум, NMDA/Mg²⁺), зоны с физической изоляцией.
- **Этап 4–5**: нейрохимия как тензоры; S7-стабилизатор («спасла проект»);
  DA/NE тензорные пульсы.
- **Этап 6 (эта сборка)**: Масштабирование (O(N) fan-in-константа);
  GABA с reversal + тройная защита V_rest (E_Cl=V_rest, точный интегратор,
  KCC2) — протокол сна; быстрый контур в CUDA Graph; гибридный «Экзамен».

## Дизайн-принципы

1. **Всё — тензоры**: ветвления только по статическим константам → весь
   контур захватывается CUDA Graph без единой host-синхронизации.
2. **Состояние — строго in-place** (`add_/mul_/copy_/index_add_`):
   анти-паттерн `t = t + 1` «замораживает» счётчик внутри графа.
3. **Торможение саморегулируется**: `E_Cl ≥ V_rest` делает GABA тормозом
   с обратной связью, а не силой, толкающей мембрану вниз.
4. **Изоляция зон — структурная**, не дисциплинарная: индексы пресинапсов
   физически не покидают свою зону, кроме явных проекций.
5. **Масштаб без изменения динамики**: fan-in постоянен → плотность связей
   и гомеостаз масштаб-инвариантны.

## Требования

- Python ≥ 3.9, PyTorch ≥ 2.0 (CUDA-сборка — для стадии GRAPHS).
- Без GPU проект полностью работоспособен (CPU), стадии CUDA Graph
  помечаются SKIP.
