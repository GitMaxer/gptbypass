# ВЕРИФИКАЦИЯ NEUROWEAVE v6.0 (CUDA Graphs + математика GABA + Экзамен)

## Запуск

**Windows:**
```bat
verify.bat
```

**Linux / macOS:**
```bash
sh verify.sh          # или: python verify_cuda_graphs.py
```

**Ручной запуск отдельных стадий:**
```bash
python scripts/run_sleep.py          # только протокол сна
python scripts/run_exam.py           # только «Экзамен» (eager)
python scripts/run_exam.py --graph   # «Экзамен» целиком в CUDA Graph
python scripts/run_scaling.py --factors 1,2,4,8
```

Требования: Python ≥ 3.9, `pip install -r requirements.txt` (torch ≥ 2.0,
для стадии GRAPHS — CUDA-сборка torch: `pip install torch --index-url
https://download.pytorch.org/whl/cu121` или новее).

## Что проверяется (6 стадий)

### [ENV] Окружение
Версия torch, устройство, имя GPU. Без CUDA стадии GRAPHS помечаются
SKIP и не считаются провалом — верификация CUDA Graph обязательна только
на GPU-машине.

### [MATH] GABA-reversal: инвариант V ≥ V_rest (ядро Этапа 6)
- **T1/T1b** — точный интегратор при глубоком торможении (g_GABA = 50 и
  500): `V_min = −70.000000 мВ` — мембрана сходится к покою и **никогда**
  не опускается ниже (допуск 1e-6). Ожидаемо: `PASS`.
- **T2** — контраст: явный Эйлер в том же режиме `расходится`
  (V_min порядка −10¹² мВ): при `tau_eff = tau_m/(1+g) << dt` явная схема
  обязана «проваливаться» ниже V_rest — потому в рантайме только точный
  экспоненциальный интегратор. Ожидаемо: `PASS (контраст показан)`.
- **T3** — патологический `E_Cl = −85 мВ` (коллапс Cl⁻, KCC2 выключен):
  мембрана проваливается до ≈ −84 мВ; с KCC2-гомеостатом
  (`E_cl = max(E_cl, V_rest)`) — ровно −70.0000. Ожидаемо: `PASS`.
- **T4** — выпуклость неподвижной точки (1000 случайных конфигураций):
  `min V_inf ≥ V_rest`. Ожидаемо: `PASS`.

Полный вывод — `MATH_GABA_REVERSAL.md`.

### [SLEEP] Протокол сна W→N1→N2→N3→REM→W
Норма: в N3 (g_GABA ≈ 3.5) `V_min = −70.0000`, частоты подавлены;
патология (E_Cl = −85, без KCC2): провал ниже покоя — контраст подтверждает
необходимость гомеостата. Ожидаемо: `PASS`.

### [GRAPHS] CUDA Graphs — быстрый контур (тензорные пульсы DA/NE внутри)
На GPU-машине:
1. захват шага `FastLoop.step()` целиком (входы, DA/NE-пульсы, мембрана,
   WTA, readout) — **один раз**;
2. эквивалентность eager ↔ graph на 60 шагах (`max|ΔV| < 1e-4`, спайки
   совпадают побитово; сравнение при `sigma_ht = 0` — RNG eager и графа
   идут разными потоками philox, при нулевом sigma вклад шума ровно 0);
3. ускорение: 2000 шагов eager vs 2000 реплеев, цель **≥ 1.5x** в
   смешанных нагрузках, **> 2x** на выделенном GPU (шаг = ~100 мелких
   ядер: eager платит запуск каждого из Python, реплей — один вызов).
Ожидаемо на GPU: `PASS` с `speedup = x2 … x10`; на CPU: `SKIP`.

### [EXAM] Гибридный режим «Экзамен»
Претрейн (readout + мягкий DA-гейтовый Хебб w_slow) → **заморозка** →
чередование блоков синтаксис ↔ логика (6 переключений, cue за 4 шага,
NE-пульс от внутреннего детектора `|ctx − ctx_ema|`):
- точность синтаксиса ≥ 0.85 (окна «нарушение чередования классов»);
- точность логики ≥ 0.85 (окна OR по парам токенов);
- WTA-следование за cue ≥ 0.90;
- **дрейф w_slow = 0 строго** (`torch.equal` по всем 16 тензорам);
- NE-пульс > 0.5 на переключениях; V_min ≥ −74 мВ (допуск 5-HT-шума).
Первые 2 окна каждого блока — фаза реконфигурации задачи (task-set
reconfiguration): не оцениваются, их отставание = «стоимость
переключения». На GPU дополнительно: весь «Экзамен» повторяется
**внутри CUDA Graph** (`run_exam --graph`) — показатели должны совпасть.

### [SCALE] Масштабирование
Факторы 1, 2, 4 (CPU: 1, 2): время шага, пиковая память, конечность
состояний, гомеостаз частот; log-log наклон времени (1.0 = линейно O(N),
fan-in фиксирован). Ожидаемо: `PASS` (наклон ≤ 1).

## Частые вопросы

- **Первый реплей медленный** — норма: прогрев кэшей; бенчмарк исключает
  прогрев (warmup 200 шагов).
- **«CUDA error: operation not permitted when stream is capturing»** —
  внутри шага появился host-синк (`.item()`/`print` тензора). В поставке
  таких нет; не добавляйте их в `FastLoop.step`.
- **Скорость ниже 2x на GPU, занятом другими задачами** — измеряйте на
  простаивающей карте; launch-overhead у мелких ядер высок, поэтому
  выигрыш тем больше, чем меньше сеть относительно драйвера.
- **Т5-HT шум и сравнение eager/graph** — сравнение траекторий всегда при
  `sigma_ht = 0` (см. GRAPHS п.2).
- **Windows-консоль и кириллица** — `verify.bat` выставляет `chcp 65001`.
