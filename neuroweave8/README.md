# NEUROWEAVE 8

Рабочая реализация цифрового спайкового организма: синтез канона
`NEUROWEAVE_SPIKER_единый_концепт_v4.0.pdf` (+ патчи CHANGELOG v4.0.1),
инженерии `neuroweave_v6` и восстановленной `neuroweave_v7restored` —
с расширениями из `docs/science_grounding.md` (литература-ориентированный
дизайн). Вычисление = память = обучение в одном контуре.

```
python -m neuroweave8.main --preset poc --steps 200 --batch 4
pytest tests/
```

## Что нового относительно v7

| Подсистема | v8 |
|---|---|
| Область | **Ламинарная колонна** L4→L2/3→L5→L6 + PV/SST вместо плоской зоны: базальный (сенсорный) и апикальный (контекстный) тракты разведены физически; дендритное плато Larkum — theta_shift L5, AND-гейт «вход И контекст» |
| Рабочая память | **θ-γ биндер** (7±2 слота, алиасинг при переполнении) + **фазовый VSA** (комплексные unit-фазовые коды, bind/unbind/bundle/cleanup, кодирование спайк-паттернов в роль-филлер) |
| Эпизодическая память | **Гиппокамп** DG→CA3→CA1: паттерн-сепарация (расширение + k-WTA), аттракторное восстановление, новизна-компаратор, приоритизированный SWR-реплей во сне по остаточной ошибке |
| Нейромодуляция | **Обучаемый мета-контроллер** над телеметрией → сетпоинты ACh/5-HT + Yu&Dayan: ACh=ожидаемая неопределённость (EMA ошибки), NE=неожидаемая (транзиент surprise → фазический аларм) |
| Поведение | **Global Workspace** с заявками компетентности: bid = уверенность × track-протокол точности (переживает эпизоды) — защита от уверенно-ошибающихся экспертов |
| Структура | **Структурная пластичность**: рост ∝ прогрессу обучения (dL/dt), критическое окно, переоткрытие окна NE-стрессом, прунинг неподтверждённого |

## Наследие, проверенное патчами канона v4.0.1

- Точный экспоненциальный интегратор мембраны + проводимостная GABA
  (E_Cl ≥ V_rest → чистый шунт) + KCC2-кламп — из v6.
- NMDA: Mg²⁺-блок Jahr–Stevens × калиброванный coincidence-gate
  (нуль при нулевом AMPA); ACh-модуляция (1+γ·ACh) база / (1−γ·ACh) апекс.
- w_fast затухает КАЖДЫЙ такт (Y1); DA-импульсы событийные
  (observe→pending→следующий такт, S4); синапсоспецифичная нормировка (S6);
  задержка шины копиями index_select (S7); консолидация — мягкий порог
  sigmoid (исправленное ур. 21); EWC ребазируется после каждого сна;
  NE — фазический фронт, сбрасывающий адаптацию; SLTT с detach (O(1)
  памяти); стохастический шум только при stochastic-флаге.

## Жизненный цикл

1. **Изоляция**: колонки обучаются локально (PredictiveHead Widrow–Hoff,
   surprise = EMA ошибки; изоляция=0 режет межобластной апикальный путь).
2. **Сборка** (`assemble()`): connect_apical + freeze w_slow — включаются
   маршруты `routes`: `'ff'` → базальный драйв L4 адресата, `'fb'` →
   апикальный контекст L5 через CorpusCallosum (задержка 5–10 тактов,
   GABA-фильтр, асимметричные проекции, транзитный DA-кредит).
3. **Бодрствование** (`behave`): tick → bids → compete → fuse → reward →
   событийный DA → Tag-and-Capture (w_fast) → эпизод в гиппокамп →
   мета-контур контроллера.
4. **Сон** (`sleep_cycle`): ACh→−0.8, 5-HT↓ (энтропия), приоритизированный
   реплей эпизодов → пороговая консолидация w_fast→w_slow → прунинг →
   пробуждение → EWC rebaseline.
5. **Медленный контур**: `maybe_sleep()` с гистерезисом по sleep_pressure
   (ур. 20); структурный рост по прогрессу.

## Демо-метрика (poc, 200 тактов)

Марковский поток vocab=16 с инверсией правила на середине эпизода
(M1_inv): точность растёт выше случайного уровня, проседает на инверсии
(адаптация w_fast), сохраняется после сна (консолидация w_slow).
Точные числа зависят от seed — это живой стохастический организм.
